AThe files the app reads and writes

PostHarvestPro runs in the browser and sends nothing to any server: the tables come in from your computer and what the app writes goes out to your downloads folder.

A.1 · What the app reads

Every tool that analyzes a table has the same data entry (Section 2.1): Open file (CSV, TXT, XLSX, ODS), Paste a table or dropping the file on …or drop the file here. The project comes in through Block 9.

WhatExtensionHow it is read
Text table.csv .tsv .txtThe separator is guessed from the first 20 lines: the tab, the semicolon or the comma, whichever appears the same number of times in all of them (quotes are respected). If the separator is not the comma, the decimal comma is accepted (12,5). The byte order mark at the beginning is ignored and empty lines are skipped.
Spreadsheet workbook.xlsx .xlsm .odsRead by the app’s own reader, without libraries. If the workbook has several sheets a selector appears and the first one opens. The old formats (.xls, .xlsb, .xlt, .xla) do not open: save them as .xlsx, .ods or .csv.
Pasted cells—Copied from a spreadsheet, with the column names in the first row; they are read as tab-separated text.
Project.jsonOpen project… in Block 9. Only a file written by the app, with "app": "PostHarvestPro" (Chapter 9).

In every case the first row holds the column names (a column without a name is called col1, col2…, and a repeated name receives _2). A cell is a number if it looks like one (with sign, decimals or exponent); otherwise it is text. Empty cells, NA, N/A, NaN, null, - and — are missing. Tables are always in long format: one row per observed unit (fruit, jar, consumer by product) and one column per variable.

After reading the table, the app proposes the column for each role by its name: it compares ignoring case, accents and signs, first the whole name and then as part of the name (Temperatura (°C) works for the temperature), in Spanish or in English. Roles marked (optional) may be left at — none —. Some lists are proposed by their content: the CATA terms are the columns with only 0 and 1, and the just-about-right attributes, those beginning with jar_. In Block 5›Mechanical damage, volumen_mm3 and energia_J fill Bruise volume (mm³), for the susceptibility and Impact energy (J), and the mass (Fruit mass (g), if there is no energy) is used only when there is no energy. In Block 4›Climacteric, the column name also proposes the units: Time unit (days or hours; dia gives days and a name ending in _h, hours) and Respiration unit (mg or mL CO₂ kg⁻¹ h⁻¹, depending on whether it contains mg or ml).

All CSV files use the comma as separator, the decimal point and Windows line breaks, and are in UTF-8 with a byte order mark so that a spreadsheet reads accents, the µ and the °. Result tables are written as they are seen: with the headers in the active language of the interface only (English with the English interface), the numbers already rounded and the intervals inside the same cell (0.500 [0.342, 0.658]); the sheet of the XLSX file carries the same name as the file. They are for reading or pasting into a document, not for computing again. The files that go to another app (the chain, the profile means, the serving plan, the field book) carry the full numbers.

iWhat the browser remembers

The browser keeps only preferences, not data: the language (postharvestpro:lang), the light or dark theme, the last tab opened in each block, the animations, the settings of the figure studio and the edits made with the ✎ editor. When you send a table to another app of the suite, it also leaves a copy in labg:handoff so that app can pick it up if you open it from the same site. To keep a piece of work, save the project.

BThe rules and formulas, gathered

The formulas the app computes and the rules with which it warns, classifies or decides, with the block where they act and their default values. They are the ones each chapter explains; here they are together for consultation at a glance.

B.1 · Quality, ripeness and color (Block 2)

Ripeness indexSSC/TA; BrimA = SSC − 2·TA (Jordan et al. 2001).
Titratable acidity% = VNaOH (mL) · N · milliequivalent weight of the acid · (volume made up / aliquot) · 100 / sample; titration to pH 8.1. To express it as another acid, only the milliequivalent weight changes.
Moisture and dry matterWith the net masses (without the dish), wet basis = (fresh − dry) / fresh · 100; dry matter = dry / fresh · 100; dry basis = (fresh − dry) / dry · 100.
Firmness1 kgf = 9.80665 N; pressure (kPa) = force (N) / plunger area (mm²) · 1000.
Weight loss% = (initial − current) / initial · 100; the rate per day, by least squares through the origin. Warning on reaching 5%: “near the limit at which many fruit shrivel”.
Chroma and hueC* = √(a*² + b*²); h° = atan2(b*, a*), from 0 to 360°. Name of the hue: ≥ 105° green, 85–105 green-yellow, 70–85 yellow, 50–70 orange, 25–50 red-orange, below that red.
Color indicesa*/b*; CCI = 1000·a* / (L*·b*); the browning (BI), whiteness (WI), yellowness (YI) and tomato color (TCI) indices of the converter.
Color differencesΔE*ab = √(ΔL*² + Δa*² + Δb*²); ΔE94 and ΔE00 (CIEDE2000). Reading of ΔE00 (Mokrzycki and Tatol 2011): < 1 imperceptible; 1–2 only for a trained observer; 2–3.5 for any observer; 3.5–5 clear difference; ≥ 5 different colors. The figure of color over time draws the line at 3.5.
McKinney index100 · Σ(class · n) / (N · highest class); it runs from 100 · lowest class / highest class (all in the lowest class: 0 if the scale starts at 0, 20 with a scale from 1 to 5) to 100, and the reading states that range. Marketable = % of units with class ≤ the Market tolerance (highest class accepted) (1 by default). Grades that are not a class are not counted, and a lot with none within the classes is left out, with a warning.
Size gradesEach class includes its minimum and excludes its maximum, except the last one. Fruit outside every class are counted apart (tile and reading); if none falls inside, there is no most frequent grade and the app warns.

B.2 · Kinetics, shelf life and rejection (Block 3)

Reaction ordersZero: C = C₀ − kt; first: C = C₀·e−kt; second: 1/C = 1/C₀ + kt. They are fitted by nonlinear least squares on the original scale (or linearized, if chosen) and compared by AIC and Akaike weight; by default Lowest AIC is used; an order that cannot be fitted is left out of the comparison, with a note. At least 3 observations at 2 times are needed.
Life to the limitThe time at which the model reaches the Acceptance limit (25 N in the example), with its confidence interval; half-life = the time to C₀/2.
Arrheniusln k = ln A − Eₐ/(RT), with T in kelvin and R = 8.314 J mol⁻¹ K⁻¹; weighted by the standard error of k if requested. At least 2 different temperatures. Block 3›Temperature opens with the starting k values of the example mango, the same ones given by Kinetic models (0.06119, 0.1569 and 0.2508 at 13, 20 and 25 °C, with C₀ = 123.736): Eₐ = 84.2 kJ/mol. Take the k values to the temperature analysis → sets the order, C₀ and the limit before filling the table, and everything is recomputed at once.
Q10(k₂/k₁)10/(T₂ − T₁) between two temperatures; from Eₐ, Q10 = exp(10·Eₐ / (R·T·(T + 10))): it is not constant, it falls as temperature rises.
Square root√k = b·(T − Tmin).
ExtrapolationA storage temperature outside those tested is marked “extrapolation” in the tiles.
Accelerated testln θ against 1/T (Arrhenius) or against T (Q10), with the prediction interval at the storage temperature; at least 3 shelf lives at 2 temperatures.
Kaplan–MeierŜ(t) = Π(1 − dᵢ/nᵢ); log interval with Var[log Ŝ] = Σ dᵢ / (nᵢ(nᵢ − dᵢ)) (Greenwood). Groups compared by the log-rank test.
Parametric modelsWeibull, log-normal, log-logistic and exponential by maximum likelihood with right censoring, compared by AIC; the time to the Tolerated rejection (%) (10 by default) and the time ratios against the reference group. Without rejected fruit (status 1) no model is fitted; a model whose maximum likelihood does not converge is left with an approximate AIC and a note.

B.3 · Respiration, ethylene and atmospheres (Block 4)

Static systemRate = slope of the gas (% per hour) / 100 · free volume / molar volume · molar mass · 1000 / mass of produce (mg kg⁻¹ h⁻¹); the free volume is that of the jar minus that of the produce (mass / density). RQ = CO₂ produced / O₂ consumed; warning if RQ > 1.3: “possible anaerobic respiration”.
Heat of respiration10.67 J per mg of CO₂ (the oxidation of a hexose); W per tonne = r · 10.67 · 1000 / 3600.
Classes (Kader 2002)Ethylene at 20 °C (µL kg⁻¹ h⁻¹): < 0.1 very low, 0.1–1 low, 1–10 moderate, 10–100 high, ≥ 100 very high. Respiration at 5 °C (mg CO₂ kg⁻¹ h⁻¹): < 5 very low, 5–10 low, 10–20 moderate, 20–40 high, 40–60 very high, above that extremely high.
ClimactericRespiratory rise = peak / previous minimum ≥ Minimum respiratory rise (×) (1.5), with the peak before the last reading; ethylene burst = peak / previous minimum ≥ Minimum ethylene rise (×) (10) or peak ≥ Minimum ethylene peak (1 µL kg⁻¹ h⁻¹). Climacteric: both (or only the respiratory one if there is no ethylene); non-climacteric: neither, with flat or falling respiration; anything else, uncertain. Peaks and ethylene lead in the chosen Time unit (“day 6”, “1 day after”).
Equilibrium atmosphereO₂ inside = O₂ outside − 100·r·W·24·L / (P·A); CO₂ analogous with the CO₂ permeability and RQ. With O₂-limited respiration (Michaelis–Menten), r = Vm·[O₂] / (Km + [O₂]·(1 + [CO₂]/Ki)). β = PCO₂/PO₂; required β = RQ·(20.95 − O₂) / (CO₂ − 0.04).
Package limitsInner O₂ < 1%: risk of anaerobiosis. A thickness outside 8–150 µm cannot be manufactured or sealed as a bag.
CoolingY = (T − Tm)/(Ti − Tm) = j·e−Ct; half-cooling = ln(2j)/C; seven-eighths = ln(8j)/C.
Heat loadField heat = m·cp·ΔT, with cp = 0.0335·water (%) + 0.837 kJ kg⁻¹ K⁻¹ (Siebel); plus the packaging and the respiration; 1 ton of refrigeration = 3.517 kW.

B.4 · Losses and mechanical damage (Block 5)

The chainEach stage loses a % of what enters it (or some kilograms) and what is lost no longer reaches the next one; value lost = kilograms lost · price at that stage. Loss index = lost / initial · 100.
Critical pointsPareto: the stages, sorted from largest to smallest, that together add up to 80% of the loss, in kilograms and in value.
Simulate improvementsThe reduction is relative: 50% is losing half of what is lost today at that stage. With a new chain, it proposes the stage that loses the most value (in the example, Venta al menudeo, the retail stage of the Spanish example data).
Mechanical damageLinear, quadratic, power (a·xb) and exponential (a·ebx) curves, the last two fitted on the log scale but with a (not ln a) in the table; compared by AIC. Energy = m·g·h.
Bruise susceptibilityBruise volume (mm³) / energy (J), averaged over the fruit with a measured bruise and positive energy (Bajema and Hyde 1998): mm³/J (135 in the example, 60 fruit). The energy is that of its column, that of the x axis if it is an energy, or m·g·h with the mass and the height. With the area instead of the volume it comes out in mm²/J, with the tile marked as a warning and a caution in the reading: it is not comparable with published values. Volume of a spherical cap = πh(3w²/4 + h²)/6.
IncidenceLogistic regression of bruised (0/1) against height; the height that bruises 50% (e50) and 10% (e10), with Fieller interval and in the unit of the axis (26.9 and 15.3 cm in the example); the threshold of the straight line, also with its unit (3.5 cm).

B.5 · Sensory evaluation (Block 6)

Guessing and discriminatorspg = 1/3 (triangle, 3-AFC, tetrad) or 1/2 (duo-trio, 2-AFC); pd = (pc − pg) / (1 − pg).
Psychometric functions2-AFC: Pc = Φ(d′/√2); duo-trio: 1 − Φ(d′/√2) − Φ(d′/√6) + 2Φ(d′/√2)Φ(d′/√6); triangle: 2∫₀^∞ [Φ(−z√3 + d′√(2/3)) + Φ(−z√3 − d′√(2/3))] φ(z) dz; 3-AFC: ∫ φ(z − d′) Φ(z)² dz; tetrad: 1 − 2∫ φ(z)[2Φ(z)Φ(z − d′) − Φ(z − d′)²] dz. d′ = 0 if pc ≤ pg.
TestDifference: p = P(X ≥ x | pc₀); similarity: p = P(X ≤ x | pc₀), with pc₀ that of pd₀. Standard error of d′ by the delta method.
PlanningThe smallest number of judges whose exact power exceeds the desired one (by default d′ 1.5, α 0.05, power 0.8); power < 0.8 is marked “low”.
A–not A · preferenced′ = z(H) − z(F), one-sided Fisher p; preference: two-sided binomial with p₀ = ½. The “no preference” answers are excluded or split half and half; if they are odd, one is dropped.
HedonicLiking = product + consumer + error; Tukey–Kramer at 5%; Friedman with the complete consumers. Unbalanced: sequential table (product first) plus the Product, adjusted for consumers row (product last), which is the effect reported; observed means.
Just-about-rightDrop = ȳjust right − ȳgroup; weighted penalty = drop · % of the group / 100; pooled-variance t. It matters if the group gathers ≥ the Consumer threshold (%) (20) and the drop is positive. Scale of 3, 5, 7 or 9 levels: with an even number, warning and hidden results (out of the report).
CATAQ = (k − 1)[kΣCj² − N²] / (kN − ΣRi²), χ² with k − 1 df; pairwise McNemar with Holm; correspondence analysis of the frequency table.
ProfileIntensity = product + judge + [session] + product × judge + error; with replicates, product F = MSproduct / MSproduct×judge; means with LSD or Tukey with that error; PCA of the means.
PanelA judge is flagged if their median p > 0.20 (“discriminates little”), their median agreement < 0.5 (“disagrees with the panel”) or their mean residual SD > 1.5 times the panel median (“repeats poorly”).
BallotsWilliams square: t orders with t even, 2t with t odd; complete balance if the judges are a multiple of the orders (6 in the triangle). Three-digit codes (100–999) without repetition.

B.6 · Trials (Block 7)

FactorialTreatment × time with type III sums of squares (by default); if the interaction is significant, treatments are compared within each time. Tukey, LSD or Dunnett against the control.
Empty cellsIf some treatment × time combination has no data, the app names it. With type III, the main effects are not estimable (df, SS, MS, F and p shown as a dash); the interaction, with fewer df, and the comparisons within each time remain valid. With type I, each effect is tested in order and the interaction loses degrees of freedom.
Repeated measuresTreatment against the between-units error; time and interaction against the within error. Sphericity by Mauchly; Greenhouse–Geisser ε = (Σλ)² / ((b − 1)Σλ²) and Huynh–Feldt ε; within each time, the pooled error with Satterthwaite degrees of freedom.
SlopesOne straight line per treatment; test of equal slopes and pairs with Holm.

B.7 · Packaging and storage (Block 8) and report (Block 9)

Pallet and containerThe load of each pallet is the produce and the boxes plus the Empty pallet weight (kg) (25); the pallets per container are limited by space or by weight.
VentingOpen area of each face (%): ≥ 5% sufficient; 3–5% in yellow; < 3% in red.
PsychrometricsSaturation pressure over water (Wagner and Pruss 2002) and over ice (Wagner et al. 2011). Produce–air deficit = pws(Tproduce) − RH·pws(Tair). The sentence “With RH at 95% instead of …” recomputes the deficit and the loss with the RH written.
Water loss% per day = k (mg kg⁻¹ s⁻¹ MPa⁻¹) · deficit (MPa) · 86,400 / 10⁶ · 100. The report flags it if it exceeds 2% per week.
CompatibilityIncompatible if the temperature ranges do not overlap, or if one produces much ethylene (high or very high class) and the other is very sensitive; warning if the humidities differ by more than 5 points, if there is a moderate ethylene risk or if one gives off odors. Pairs at risk counts every pair with some warning, even if it is also incompatible (it says so below: “3 also incompatible”).
Report recommendationsOnly with the checked sections (by default, those you used; those that keep only the example values remain unchecked). Fixed rules: the life to the limit of each group; with Eₐ, the % of life lost per degree (between 10 and 11 °C); climacteric; respiration > 40 mg CO₂ kg⁻¹ h⁻¹; package outside the window; the stage with the largest value lost; drops below the height that bruises 10% (with that of 50%, in its unit); the most liked product; water loss > 2% per week; boxes with < 5% open area; incompatible products.

CGlossary

The postharvest, sensory and statistical terms the manual uses, in the sense in which the app uses them.

TermMeaning
A–not ATest in which the judge learns sample “A” and then says, for each sample, whether it is “A” or not.
AICAkaike information criterion: compares models by their fit penalized by the number of parameters; the smallest is the best. The Akaike weight is the relative probability of each model.
Modified atmosphereThe mixture of O₂ and CO₂ that forms inside a closed package because the produce respires and the film lets the gases through at a certain rate.
β (beta)The ratio of the permeabilities of a film to CO₂ and to O₂; it sets the slope of the atmospheres the film can give.
BrimARipeness index that subtracts twice the acidity from the soluble solids: it weighs acidity as the tongue perceives it.
CATA“Check all that apply”: the consumer checks, from a list, the terms that describe the product.
CCICitrus color index, 1000·a* / (L*·b*): negative in green, positive in orange.
CensoringA fruit that was still acceptable when the trial ended: its time to rejection is known to be longer than the one observed, not what it is.
ClimactericProduce whose ripening comes with a rise in respiration and a burst of ethylene; it can ripen after harvest.
Respiratory quotient (RQ)CO₂ produced divided by O₂ consumed; near 1 with sugars as substrate; well above 1, possible anaerobiosis.
Chroma (C*) and hue (h°)The vividness of the color and its angle on the CIELAB color wheel (0° red, 90° yellow, 180° green).
d′ (d prime)The size of a sensory difference in standard deviations of the sensation (Thurstonian model); comparable across methods.
ΔE00The difference between two colors by the CIEDE2000 formula, which corrects the distortions of the L*a*b* space.
Vapor pressure deficitThe difference between the vapor pressure at the surface of the produce and that of the air: the force that dehydrates it.
Unbalanced (design)A design in which not every combination has the same number of data (a consumer who did not taste a product, an empty cell): the order of the effects changes the sums of squares.
e10 · e50The drop height (or energy) that bruises 10% and 50% of the fruit, from the logistic regression of the incidence.
Activation energy (Eₐ)How much temperature speeds up a reaction; with a high Eₐ, deterioration is more sensitive to cold and heat.
Sphericity · εAssumption of repeated measures: the differences between any pair of times have the same variance. ε (Greenhouse–Geisser, Huynh–Feldt) measures how far it departs, and corrects the degrees of freedom.
Steady stateIn a package or a chamber with flow, the moment when the concentrations no longer change because what comes in equals what goes out or is consumed.
Hedonic (scale)Nine-point liking scale, from “dislike extremely” (1) to “like extremely” (9).
Holm (adjustment)Correction of the p-values when several tests are run at once.
McKinney indexThe mean severity on a damage scale, as a % of the maximum possible.
Loss indexWhat is lost along the chain, as a % of what came in.
Cooling j and CThe lag factor (j) and the cooling coefficient (C) of the curve Y = j·e−Ct.
Kaplan–MeierEstimator of the proportion of fruit still acceptable at each time that makes use of the censored ones.
Limit (of acceptance)The value of an attribute beyond which the produce is no longer acceptable (25 N of firmness in the example).
LSD · Tukey · DunnettMean comparisons: Fisher’s least significant difference (the least strict), Tukey’s (all pairs) and Dunnett’s (each treatment against a control).
Reaction orderThe way the rate of deterioration depends on the attribute itself: constant (zero), proportional (first) or squared (second).
pc · pdThe proportion correct and the proportion of discriminators (those who really notice the difference) in a discrimination test.
Penalty (JAR)The drop in liking of those who find an attribute “too little” or “too much”, weighted by how many they are.
PowerThe probability that a test detects a difference that does exist.
PrecoolingRemoving the field heat from the produce as soon as possible after harvest.
Just-about-right (JAR)Scale that asks whether an attribute is “too little”, “just right” or “too much”.
Q10How many times deterioration speeds up with 10 °C more.
Cochran’s QTest of whether the proportion of “yes” answers to a question differs between several products evaluated by the same people.
Time ratioHow many times a treatment lengthens (or shortens) the time to rejection relative to the reference one.
SSC/TASoluble solids content (°Brix) divided by titratable acidity (%): the classic index of ripeness and flavor.
Type I and type III sums of squaresSequential (each effect adjusted for the previous ones) or adjusted (each effect adjusted for all the others). They agree with balanced data; with empty cells, type III cannot test the main effects.
Bruise susceptibilityThe bruise volume produced by each joule of impact, in mm³/J (Bajema and Hyde 1998); with the area instead of the volume, mm²/J, which is not comparable with published values.
TminThe theoretical temperature at which deterioration would stop, from the square-root model.
Shelf lifeThe time the produce stays acceptable under given conditions.
Williams (square)Presentation order of the samples balanced for position and for the previous sample.

DWhen something does not work

The messages of the app, as they appear with the English interface, with what they usually mean and what to do. The ellipses stand for the part of the message that changes (a name, a number).

MessageWhat is happening and what to do
Opening a table (all tools)
“That old spreadsheet format cannot be opened; save it as .xlsx, .ods or .csv.”An .xls or .xlsb. Save it again in a format the app reads.
“the file is not a spreadsheet in the .xlsx, .xlsm or .ods format” · “the workbook has no xl/workbook.xml: it is not an .xlsx or .xlsm file” · “the file has no content.xml: it is not an .ods spreadsheet”The extension does not match the content (a renamed CSV, a damaged file). EThe tool: license and how to cite it

E.1 · What it is and what it is not

PostHarvestPro is written for this program: the spreadsheet reader, the kinetic and survival models, the statistics, the psychrometrics, the figures, the report and the illustrations are in its own code, which can be read. It uses no third-party computing libraries, ships no typefaces (it uses the computer’s fonts), has no minified code or build steps and loads nothing from the network: that is why it opens with a double click and without a connection. The only links to the outside—the suite portal and the apps to which tables are sent—are followed only if you click them.

The only third-party elements are the line icons of the suite’s common modules (the block navigator, the figure studio and the animations button), taken from the Lucide project under the ISC license (and MIT for those Lucide inherited from the Feather project), both permissive and compatible with the GPL; the file LICENSES-TERCEROS.md, in the program folder, lists them with the text of their licenses. The example data are simulated (Appendix A). The app implements published methods, each one cited to its original source in the code, at the foot of each result, on the app’s home page and in the methods of the report (Appendix F).
